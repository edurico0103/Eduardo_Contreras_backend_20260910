# Eduardo Contreras Backend

Proyecto académico desarrollado en PHP utilizando XAMPP.

## Tecnologías

- PHP
- MySQL
- XAMPP
- Git
- GitHub

## Archivos principales

- `index.php` - Archivo principal de la aplicación.
- `conn.php` - Configuración de conexión a la base de datos.

## Ejecución local

Colocar el proyecto dentro de:

`C:\xampp\htdocs\`

Iniciar Apache y MySQL desde XAMPP y acceder desde el navegador.
